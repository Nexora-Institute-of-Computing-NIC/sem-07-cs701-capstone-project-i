# CS701 — Capstone Project I — PLAN

**Semester:** 7 · **Credits:** 6 · **Level:** Advanced-Professional
**Theory:** 15 hrs · **Lab:** 60 hrs · **Tools:** Your chosen stack; Git + GitHub for everything

## Project Format
A two-semester individual or paired capstone. Semester 7 focuses on problem definition, research, design, and a working prototype. Semester 8 completes the build and produces the thesis.

## Syllabus

### Unit 1 — Project Definition (3 lectures)
1. Choosing a capstone problem — depth over breadth
2. Feasibility analysis — scope, time, skills, resources
3. Writing a strong project proposal

### Unit 2 — Literature and Research (3 lectures)
1. Finding relevant papers — ACM, IEEE, arXiv, Google Scholar
2. Reading a paper efficiently — structure, contributions, methods
3. Writing a literature review

### Unit 3 — Design and Planning (3 lectures)
1. System architecture for a large project
2. Breaking scope into milestones — Gantt and sprints
3. Risk identification and contingency planning

### Unit 4 — Prototyping and Iteration (3 lectures)
1. Building the thinnest possible vertical slice
2. Early user feedback and course correction
3. Documenting decisions — ADRs

### Unit 5 — Mid-Year Review (3 lectures)
1. Writing a technical progress report
2. Presenting progress — pitch, demo, evidence
3. Planning Semester 8 — scope adjustment

## Practical Labs (15 — weekly milestones)

1. Project brainstorming — 3 ideas per student
2. Idea selection — pick one, justify with reasoning
3. Feasibility analysis — one page
4. Proposal draft — problem, objectives, scope, deliverables
5. Proposal revision after review
6. Literature scan — 10 papers identified and skimmed
7. First literature review draft — 5 papers summarised
8. Literature review final version
9. System architecture diagram and component breakdown
10. Milestone plan — semester 7 and 8 roadmap
11. Risk register — top 5 risks with mitigation
12. Vertical slice prototype — something end-to-end working
13. Early user testing — 2–3 users, notes captured
14. Mid-year progress report submitted
15. Mid-year demo and revised plan for Semester 8

## Deliverables

- `PROPOSAL.md` — problem, objectives, scope, deliverables
- `LITERATURE.md` — 10+ papers reviewed, positioned against the project
- `DESIGN.md` — architecture diagram, component responsibilities, key decisions
- `PLAN.md` — milestones and Gantt for both semesters
- `RISK.md` — risk register with mitigations
- `PROGRESS.md` — mid-year report
- A working prototype (documented in repo)
- Demo video (5 minutes)
